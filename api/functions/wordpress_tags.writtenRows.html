      The post ids a write to wp_posts or wp_postmeta names, or undefined when it does not name them in a shape that cannot be misread.

      Accepted: an UPDATE or DELETE of one table whose WHERE is a conjunction holding ID = n (post_id = n for meta) or ID IN (n, ...), and a single-row INSERT into wp_posts, whose id is the one the database reported. An OR, a subselect, a join, a parenthesis outside an IN list, BETWEEN or an upsert is undefined, and so is every other table. Extra AND terms only narrow a write, so the listed ids are a superset of the rows it touched.
