Mail

Mail Setup reports which step sending is waiting on. It reads the Cloudflare account connected on the Deploy page, so connect one first; a token that cannot read Email Routing is reported as a short permission rather than as a step you are waiting on.

On the free Workers plan there is no outbound sending except to verified destination addresses on your own routing domains. Registration and password-reset mail goes to addresses your visitors chose, and those are not verified destinations, so on free those messages are refused rather than delivered. Reaching an arbitrary recipient needs a third-party relay through MAIL_TRANSPORT=smtp, or a paid plan.

Restore From A Recovery Point

Cloudflare keeps a 30-day change log for this site's database. Recovering to a point in it REPLACES the database on the object's next start, so the confirmation asks you to type the word. Read the points above first; the bookmark goes here.

Replaying a dump you uploaded is a different thing and is not here: it takes SQL this site did not write, so it stays behind PW_DIAGNOSTICS with the rest of the arbitrary-SQL surface.
