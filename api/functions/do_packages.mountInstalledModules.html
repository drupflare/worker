    Function mountInstalledModules

    • mountInstalledModules(site: SitePhpDurableObject, binary: SiteBinary): number

      Mounts every site-installed module file (from cfw_module_file) into the interpreter's filesystem, read on first open; the counterpart to mountDriver() for packed modules.

      Only paths and sizes are read at boot: loading every source held each twice in JavaScript (1,040 files, 6.1 MB for one site) and reset the isolate. A clean node is dropped again past INSTALLED_FS_BUDGET_BYTES. Unconditional, since core.extension names these modules.
