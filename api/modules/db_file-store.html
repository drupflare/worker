    Module db/file-store

    Durable file storage in ctx.storage.sql, chunked because a record caps at 2,199,995 bytes. R2 is an offload: a failing bucket degrades to serving from the object. With FILE_STORE=r2 a file whose put was verified is evicted from the object after a grace window and R2 holds the only copy of its bytes.
