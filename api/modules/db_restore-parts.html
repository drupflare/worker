    Module db/restore-parts

    A restore sent in parts, for a dump above the single-body ceiling.

    The client declares the dump (size, part count, sha256), sends statement-aligned parts in any order, and commits. A part is verified and parsed when it arrives and stored whole in one row; a commit verifies the whole digest, then writes the replay chunks storeImport() would have written, a few parts per call, so no call holds more than one part of the dump.
