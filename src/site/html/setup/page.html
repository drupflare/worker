Set Up This Site

Drupal is installed and serving, but nobody has claimed it yet. Claiming it sets the administrator password, gives that account the Site Owner role, and issues the owner token. Until then, anyone who reaches this URL can claim it.

Or from a terminal:

curl -X POST "__CFW_ORIGIN__/firstrun" \
  -H 'content-type: application/json' \
  -d '{"siteName":"My Site","adminMail":"you@example.com"}'
