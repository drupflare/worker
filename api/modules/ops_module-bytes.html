    Module ops/module-bytes

    How a delivered file's bytes sit in a TEXT column.

    cfw_module_file.source and cfw_module_blob.source are TEXT, and SQLite cuts TEXT at its first NUL and a UTF-8 round trip rewrites any byte sequence that is not text. A file that survives that round trip is stored as the text it is; every other file is stored as this mark followed by its base64, so one string still carries every file and the text paths (plans, comparisons, rollback) keep working over strings.
