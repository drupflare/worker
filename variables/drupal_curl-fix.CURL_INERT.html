    Variable CURL_INERTConst

    CURL_INERT: Record<string, number> = ...

    Constants a caller reads but the shim does not act on.

    Defined because an undefined constant is a fatal Error in PHP 8 -- so omitting them turns a silently-ignored option into a dead site. CurlShim::setopt() REFUSES an option it does not understand rather than dropping it, so defining the name here does not imply it is honoured; it only means the caller gets a refusal instead of a crash while composing the request.
