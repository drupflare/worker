    What a repeat is allowed to grow past the computed cap: 8 MiB by default.

    The cap holds the 128 MiB isolate away from the platform's memory kill with 4 MiB of margin, and the notes record the kill's cliff at 108 MiB of linear memory with the JS side resident. A run that was refused started from a warm interpreter; a fresh boot has the most room (E2 measured 16 to 48 MiB of headroom right after a render against 36 steady), and a deployed Thunder config export that the 104 MiB cap still refused at 108.9 to 109.2 MiB ran without a platform kill at 128 MB total. Stock Drupal never reaches 96 MiB, so the allowance only engages for heavy routes.
