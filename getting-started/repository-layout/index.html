Data Risk

assets/drupal/site.sqlite is the packed Drupal database. scripts/drupal/install-site-db.php builds it from nothing (bun run build:site-db, with docs/architecture/database.md as the recipe), and it is tracked, so the copy in the tree is the one that ships. Two other lineages exist in the drupflare-cdn bucket: .pack-backup/site.sqlite.bak, which is the rollback point for an earlier lineage, and an older hand-trimmed artifact from a different one. The SQLite header change counter is what orders them.

bun run backup:cdn archives a key's remote bytes to snapshots/<name>.<sha12> before replacing them, so nothing is lost by replacing one, and records the archive in cdn-manifest.json in the same run, so the manifest is the only file left to commit. It refuses for a tracked file with uncommitted changes, where the bytes going up are recorded nowhere. bun run backup:verify compares every key by size and ETag.

.pack-backup/

7.2 MB, one file, and it stays. It is the rollback point for an earlier lineage of the packed database (7,585,792 bytes, against 5,832,704 for the current one), and bun run bake:pack overwrites it on its next run (the snapshot step of scripts/bake-pack.ts). Its content is also in the bucket at snapshots/site.sqlite.064105ca7223.

Clean Clone to Deploy

A clean clone reaches a deployed worker through the scripts in package.json.

flowchart TD
  A["git clone"] --> B["bun install"]
  B --> C["postinstall: restore the interpreter"]
  C --> D["bun run hydrate"]
  D --> E{"Release payload?"}
  E -- "yes" --> F["assets/ and .interp/ in place"]
  E -- "no" --> G["bun run build:local"]
  G --> F
  F --> H["bun run deploy"]

bun install restores two of the three .interp/ files, and hydrate or build:local supplies the rest. bun run deploy is wrangler deploy -c wrangler.jsonc. Workers Builds runs bun run hydrate as its build command (build.command in wrangler.jsonc), so its build takes the same route. A managed deployment uses wrangler.managed.jsonc instead, which adds the R2 and send_email bindings; see Configuration. Building From Source has the two routes in full.
