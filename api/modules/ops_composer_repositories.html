    Module ops/composer/repositories

    Composer repositories beyond Packagist and packages.drupal.org: the ones a project lists under repositories, and Asset Packagist, which serves the bower-asset/* and npm-asset/* names.

    Asset Packagist publishes no p2 documents. Its packages.json names a provider index, one large document mapping every package to the hash its own document is addressed by. The index is scanned as a stream for the one name wanted, so it is never held in memory, and each name found is remembered for the life of the isolate.
