    Variable LEAK_OPEN_SESSIONConst

    LEAK_OPEN_SESSION: string = ...

    Leaves the session manager open the way a request that never reached save() would.

    A BigPipeResponse keeps the session open and closes it in sendContent(); if that throws, the request ends with started true and closed false. The next SessionManager::start() then returns early, loadSession() (the only code that re-binds the session bags) never runs, and the flash bag still references the previous visitor's array.

    No ordinary request reaches this state on this runtime (measured), so a probe is the only way to exercise the reset.

    Returns

    the flags it set and the flash bag it left behind, so a vacuous run is visible
