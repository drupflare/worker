    Optionalorigin

    origin?: string

    the scheme://host[:port] a cron fragment boots Drupal against.

    Cron is where mail is sent, and user_pass_reset_url() builds an absolute link from the request -- so booted against the default, every link Drupal mails points the recipient at their own machine. Empty leaves the old behaviour, which is correct for a probe.
