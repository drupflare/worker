Requires the External Authentication Module

The host verifies the provider's token and hands Drupal a single-use ticket; drupal/externalauth is what maps that identity onto an account, and no contrib module ships in the packed tree. Install it from Extend before the first login, or a verified login has nowhere to land.

What a Login Refuses

  • a signature from a key outside the provider's JWKS
  • a token whose iss is not the issuer above
  • a token whose aud belongs to another client of the same provider
  • an expired token
  • a nonce from a different login

The signing algorithm is taken from the key rather than from the token header, and the account is keyed by issuer and subject together, so a subject from a newly configured issuer cannot take over an existing account.
