    Module ops/spool

    The spool shadow trial: the mode levers, the paths spool owns, and the version vector the object keeps for it.

    Shadow mode never serves a page from a device. It decorates eligible pages, answers /.spool/* and /spool-sw.js, and lets the service worker record what it could have served. The vector is a map from tag to the generation of its last change, held in memory: it writes no row.
