Add a Remote

Paste a repository URL or owner/repo. Leave the branch empty to follow the repository's default. A public repository over Any Git Remote needs no token at all.

The token is stored in this site's own database, never in KV: KV is operator-writable and nothing there may change what a site can reach.

How a Pull Works

The transport is git's own smart HTTP, so any host that serves a repository works. A poll is a ref advertisement and costs a few hundred bytes when nothing has moved. A pull asks for one commit at depth 1, reads the packfile, and writes each file as its own row.

Only mountable files are kept: PHP, YAML, Twig, JS and CSS, with tests, vendor/ and node_modules/ dropped. Module names come from *.info.yml, so a repository holding several modules installs all of them at their own paths.

After a pull the Drupal kernel is booted against the new tree. If it fails, the previous files are restored and the site keeps serving.

What Gets Written Back

A commit status on the pushed sha, with a state, a context and a link back to this site. Every provider with an API supports it and an access token can write it.

GitHub's Checks API carries annotations and per-line output, and only a GitHub App can write one. A pasted token is refused with Resource not accessible by personal access token, so this page does not offer check runs.
