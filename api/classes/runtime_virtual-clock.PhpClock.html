    Class PhpClock

    The clock PHP reads.

    The platform advances Date.now() and performance.now() only at I/O, so inside one synchronous run they hold still and every loop bounded by time never ends. This clock returns max(real, base + calls * kappa, last + step), capped at real + maxAhead, and takes a new base from the real clock at every run start. A read never goes back inside a run; across runs the clock returns to the platform's, which steps it back only by the amount the last run overshot.
