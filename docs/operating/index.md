# Operating

Pages for the person who runs a Drupflare site: the surfaces an owner works from, getting a site back after a bad change, delivering code from a git host, an external database, interpreter updates and replica lanes.

## Pages

- [Administration](administration.md): the surfaces an owner operates a site from, and how each is authorised.
- [Recovery](recovery.md): the four ways a site moves backwards and how to come back.
- [Git Remotes](git-remotes.md): delivering modules and themes from a git host.
- [External Databases and Hyperdrive](external-database/index.md): Hyperdrive and external databases, and what they change.
- [PHP Interpreter Update Delivery](php-update-delivery/index.md): how a new PHP interpreter build reaches a deployed site.
- [Replica Lanes](replica-lanes.md): read replicas for a site, what a lane buys and how it is built.

Every variable and binding these pages mention is indexed on [Configuration](../configuration/index.md).
