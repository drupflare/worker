    Module ops/outbox

    The durable outbox the worker's outside effects run through: mail, outbound HTTP and Redis, and the cron firing. One table per lane, so a lane drains only its own rows, each with its own effect, width and lease.

    The rules are folio's: a row is claimed and flushed before its effect runs, so a successor that finds a running row with an expired lease knows the effect may have run. A resend kind runs again with the same key (at least once, dedupable by the receiver), a report kind ends as failed and never runs again (at most once). A kind with no policy is report.
