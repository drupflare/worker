    Variable MANDATORY_STATEConst

    MANDATORY_STATE: readonly { collection: string; name: string }[] = ...

    State every replica must hold before it may be VERIFIED, as (collection, name) in key_value.

    Checked against the classifier rather than trusted on its own, so a key that stops being authoritative there cannot stay mandatory here unnoticed. mandatoryStateDisagreements is that check, and it runs in the gate rather than at runtime: it compares two declarations in this repository, so a drift should fail a build, not a request.

    Each entry is here because a replica cannot produce it correctly on its own:

    • system.private_key keys CSRF tokens; two minters issue tokens the other rejects.
    • system.cron_key authenticates the cron endpoint; a second value is a second valid URL.
    • install_time and install_task say the install finished; absent, Drupal may route to the installer, which on a replica would attempt to install over replicated state.
